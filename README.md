# Arduino Mega 2560 Byte Array Generator 1.0.0

![MAX72XX Image](https://github.com/NeuralCortex/MAX72XX/blob/main/images/max72xx.png)

## Description

This Swing-based application enables users to graphically create byte arrays for the Arduino Mega 2560 controller in combination with the MAX72XX device. 

To run the application outside Apache NetBeans, copy the `lib` and `images` folders, along with the JAR file from the `target` directory of the NetBeans project, to a folder of your choice. As a Swing application, you can launch it by double-clicking the JAR file. An `.ino` test file is included in the project folder for testing with the Arduino IDE.

## Requirements

- [Apache NetBeans IDE 27](https://netbeans.apache.org/front/main/index.html) (for development)
- [Arduino IDE 2.3.6](https://www.arduino.cc/en/software/)
- Arduino Mega 2560 controller (or compatible)
- MAX72XX device
- USB cable

## Installation

1. **Set up the development environment**:
   - Install Apache NetBeans IDE 25 for project development (optional for running the JAR).
   - Install Arduino IDE 2.3.6 for uploading the `.ino` test file to the Arduino Mega 2560.
2. **Copy the application files**:
   - Locate the `target` directory in the NetBeans project.
   - Copy the `lib`, `images`, and JAR file (e.g., `MAX7219-1.0.0.jar`) to a directory of your choice.
3. **Connect hardware**:
   - Connect the MAX72XX device to the Arduino Mega 2560.
   - Use a USB cable to connect the Arduino Mega 2560 to your computer.

## Using the Application

1. Launch the application by double-clicking the JAR file or using the provided scripts.
2. Use the graphical interface to create byte arrays for the MAX72XX device.
3. Export or copy the generated byte arrays to the `.ino` test file or your Arduino sketch.
4. Upload the sketch to the Arduino Mega 2560 using the Arduino IDE.

## Troubleshooting

- **JAR File Not Running**: Ensure Java is installed and the `lib` and `images` folders are in the same directory as the JAR file.
- **Arduino Upload Issues**: Verify the Arduino Mega 2560 is connected via USB and selected in the Arduino IDE.
- **MAX72XX Not Responding**: Check the wiring between the MAX72XX device and the Arduino Mega 2560.
- **Missing Dependencies**: Ensure all required libraries for the `.ino` file are installed in the Arduino IDE.
